# Source and result identities

The compact calculator and its independent reducers descend from research source based on commit `997b28063d9fa01fcff4e978b7acb013ca18255a`. The source tree was not necessarily clean; a commit alone is insufficient provenance. Packaged [semantic metadata](../../src/tape_data_product/resources/feature_semantics.json) preserves historical definition digests and the explicit mapping to installed semantic constants. Installed source files and required JSON resources, together with runtime versions, receive new implementation identities.

The feature and query regression suite checks mathematical and timing parity after migration. Numerical equality does not imply byte-identical manifests or authorize reusing an old approval/run identity. Historical manifests remain evidence of their original implementation. Current stage receipts bind explicit parameters, inputs and outputs to current installed code.

The seven existing report figures and aggregate count files retain their original [publication identities](../../reports/report_assets/publication_manifest.json). The [report lineage](../report-lineage.md) distinguishes those imported results from new numerical generation and synthetic demonstration. Acquisition and analysis source attribution is retained in compact package metadata; detailed extraction and execution records are private, outside the repository and wheel.

No historical six-month calculation, remote backup or publication is implied by source migration. A verified local output does not prove predictive usefulness, trading expectancy or redistribution rights.
