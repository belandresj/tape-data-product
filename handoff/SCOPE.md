# Curated scope and dependency boundary

This checkout preserves compact feature generation, compact partition verification, feature-only causal cohort retrieval, relevant regression fixtures, implemented contracts and a small descriptive pilot summary. It is intended as the maintained product repository after the preservation conditions in [MIGRATION.md](MIGRATION.md) are met.

| Included group | Why it is needed |
|---|---|
| Direct calculator, market-state decoder, rolling/economic upstream reducers | Existing event ordering, duration integration, maturity, support, halt and null semantics |
| Compact schemas/writer/storage, all-feature schema/moments/reference modules | Eighteen fields, physical partition integrity and independent numerical reconstruction |
| Cohort config/state/reader/cache/output/pipeline/supervisor/verifier | Normalized query identity, causal membership, immutable input checks, bounded writes and resumable date transactions |
| Release/preview/snapshot/inventory modules | Actual transitive reader, manifest-compatibility and source-identity dependencies |
| July/all-feature/older economic modules and tiny tests | Retained reference calculation, fake storage clients and regression dependencies; historical names do not mean removable code |

| Selected 300s config, four-variant generator and bounded synthetic demo | Repeatable local use without private resources |
| Pilot aggregate/provenance JSON and concise report | Completed descriptive evidence without raw or row-level vendor data |

The dependency graph and original per-file SHA-256 values are in [provenance.json](provenance.json). The source was a dirty working tree based on commit `997b28063d9fa01fcff4e978b7acb013ca18255a`; that commit alone cannot reconstruct the copied code. Per-file hashes identify the actual working-copy bytes. The exact proposed Git inventory is in [FILE_INVENTORY.md](FILE_INVENTORY.md).

No sibling repository is imported. Paths derive from `__file__` or explicit arguments. The query's historical release restriction is preserved and documented. Public arbitrary-release ingestion, a wheel-distributed API, and automatic acquisition of the proprietary vendor universe are not advertised capabilities.

## Copy-only changes

- Added dependency/environment metadata, demo, offline test guard, documentation, concise summaries and publication checks.
- Expanded `tape_cohort_pipeline.QUERY_FILES` to include its transitive local dependencies and runtime-hashed contract document. The original list omitted dependencies. This changes run identity and forces replanning; it does not change numerical features, eligibility or state transitions.
- Made the retained older reference runner report null Git revision when run from an archive or a fresh repository without HEAD. It still binds the actual revision when available.
- Converted Markdown links to excluded source documents into clearly labeled textual provenance references. Equations and normative feature definitions are unchanged; edited document bytes have new hashes. Upstream runtime-derived document identities therefore change. Never present a new artifact as having the old calculation identity or reuse an old plan.

The direct calculator, compact schema, semantic decoder, query config normalizer, query reader and state machine remain byte-identical to the copied source. The synthetic and regression verification report distinguishes numerical tests from source-data and execution evidence.

## Exclusions and preservation

| Excluded | Reason and preservation status |
|---|---|
| Original `.git` history and dirty-tree history | Potential unwanted artifacts; no history imported. Not backed up by this repository. |
| `.env`, credentials, account configuration and operational logs | Private; owner must preserve securely outside Git if needed. |
| Raw/cached market data and derived event-level Parquet | Rights and size; existing R2 is the intended durable store, but this task did not audit remote completeness. |
| SQLite/DuckDB catalogs, large manifests, release-capture bodies | Private reproduction inputs remain outside the curated checkout. Their required identities/layout are documented. |
| Overnight plans, job receipts, partial outputs and implementation-bound approvals | Must remain with their original workspace/job until completion and explicit preservation review. |
| Failed attempts, research iterations, unused chart pipelines and large figure exports | Not required by the selected workflow. Exclusion is not evidence that they are expendable. |
| Source report draft and unverified empirical plots | Mixed development populations and pending corrections; replaced with a qualified completed-pilot summary. |

No new license was invented, no data redistribution right was assumed, and no full archive was created. The existing source notices in retained code remain intact. This is a curated local snapshot until a remote push succeeds; a local commit is not an off-machine backup.
